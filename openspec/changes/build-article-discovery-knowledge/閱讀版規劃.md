# 文章知識庫與語意搜尋規劃

本文件是繁體中文導讀；正式規格、技術契約與任務在 proposal.md、specs、design.md、tasks.md。依使用者 2026-10-21 指示，AI 問答暫緩，本次不實作生成回答的模型、答案 API 或問答介面。先前版本保留在 history/initial-plan-with-answers，僅供追溯，不是目前的實作範圍。

## 現有架構如何接上向量模型

目前公開站是 Astro 靜態網站，已部署於 GitHub Pages；搜尋頁讀取 discovery-manifest.json 與同版本的文章索引／段落資料，舊 search-index.json 保留相容性。正式站目前只使用關鍵字搜尋；小型公開搜尋 Worker 的雲端接線仍是未啟用規劃。現有 Admin Worker 負責登入、編輯與發布，搜尋服務不取得其管理權限。

目前正式發布流程：

公開閱讀清單 → 擷取合資格公開文章與段落 → 產生版本化靜態索引與文章關聯 → GitHub Pages 部署 → 正式 manifest／資產讀回。

未啟用的雲端發布流程規劃：

公開閱讀清單 → 擷取公開文章與段落 → 向量模型計算段落向量 → 存入 Vectorize → 確認新版網站上線 → 啟用同版本搜尋索引。

目前讀者搜尋流程：

既有單一搜尋框 → 搜尋頁 → 當期靜態文章索引與段落 → 中文關鍵字排名 → 文章結果與分頁。

另行授權後才可能接上的雲端流程：

既有搜尋框 → 搜尋頁 → 搜尋 API → 相同向量模型計算查詢向量 → Vectorize 找相近段落 → 合併關鍵字排名 → 顯示文章標題、原文段落及連結。

向量模型只把文字轉成數值，沒有生成回答的步驟。Cloudflare Workers AI 是模型執行服務；Vectorize 是保存與比對文章向量的索引，不會替文字產生向量。依使用者最新指示，在無法確認 EmbeddingGemma 免費額度前，暫時使用 BAAI 的 BGE-M3，規劃採 1,024 維。這是對非中國背景模型偏好的單一、暫時例外，不授權其他中國背景模型或 BGE 重排模型。EmbeddingGemma 保留為未來替換方向。文章與查詢必須用相同模型與設定；更換模型需要重建相容的索引。

## 模型費率與免費額度的查核結果

2026-10-21 已查官方模型頁、計價表、文件庫問題與登入後模型目錄。Cloudflare 提供 EmbeddingGemma，且標示 Beta；但目前仍沒有查到本模型的獨立單價、Neurons 換算或適用的明確免費待遇。平台每日一萬 Neurons 免費，不足以推算 EmbeddingGemma 可免費處理多少文章或搜尋；舊的 Beta 免費公告也不能作為現行保證。

完整來源、控制台查核與限制保留在 embeddinggemma-pricing-verification-20261021.md。EmbeddingGemma 費率仍未核實，不宣稱已證實免費。暫用的 BGE-M3 已有官方每百萬輸入 tokens 為 1,075 Neurons 的換算，但還須核對帳戶實際剩餘免費額度及供應商的無付費超額限制，才能啟用；此為雲端啟用前的條件；後續已授權的 Ollama 本機比較另有紀錄，不代表雲端已呼叫或啟用。

向量索引本身可獨立估算：暫用 BGE-M3，假設三百段、每段 1,024 維，需要 307,200 個儲存維度，約占 Vectorize 免費儲存額度 6.1％。這是規劃時三百段的示例，正式當期已是２６３３段，不能沿用示例當成當期容量或整套服務免費的證明。

## 接在哪些地方

- src/pages/search-index.json.ts：沿用公開文章來源，增加獨立、有版本的文章庫與段落資料，保留舊搜尋索引相容性。
- scripts/discovery：在既有網站發布流程準備及更新文章向量；未變動且設定一致的結果可以沿用。
- apps/search-worker：新增公開搜尋 API，使用模型與向量索引的服務綁定，核對公開版本、限制用量及回傳文章結果；不開放公開寫入向量。
- src/pages/search.astro：接收語意搜尋結果，合併關鍵字排序，維持現有導覽列搜尋框及網址查詢參數。
- 公開文章頁：使用預先計算的引用、反向連結、相關文章及延伸閱讀；讀者開文章不需要模型呼叫。

## 第一階段：先改善現有靜態網站

自動整理公開文章、關鍵字、明確定義的縮寫／同義詞、引用與反向連結，產生相關文章與有依據的延伸閱讀。

關鍵字搜尋已加入中文斷詞、標題優先、命中段落、安全醒目標示、分頁、可分享的查詢／頁碼、無結果提示與重試。依使用者最後確認，不顯示主題／系列／排序／模式選單、建議用詞或額外說明，舊篩選參數不再暗中限制結果。此階段不需要外部模型。

文章版面延續文字列表與分隔線，保留現有閱讀寬度、明暗主題及系列導覽；推薦數量每組最多三篇，沒有合適內容則隱藏。

## 第二階段：語意搜尋

雲端語意搜尋仍未啟用；例如以不同說法找到相同意思文章的能力，須另行確認模型、費用、隱私、接線與啟用方式。本機前景 BGE-M3 已能沿用同一搜尋表單直接送出；不能把本機接線當成公開站已使用模型，也不恢復被取消的選單或建議用詞。

每次未命中可重用快取的語意查詢，需要計算查詢向量；文章向量已提前計算。即使沒有 AI 問答，這仍是有模型執行與遠端用量成本的功能。一般閱讀、預先產生的推薦及關鍵字搜尋不呼叫模型。

建議使用獨立 Cloudflare 搜尋 Worker、Workers AI 的 BGE-M3 與 Vectorize（僅限本次明確授權的暫時例外）。不加入 AI Search 預設向量模型、重排模型或 LLM 查詢改寫；全部只回傳既有文章與段落。少量獨立 D1 記錄用來協調公開 API 的共同額度，避免多個並行請求突破預算；不混用後台資料庫。這些服務只在語意模式需要，第一階段不依賴它們。

## 自動更新、失敗與資料邊界

公開新增、修改、改網址、退回草稿或刪除，都跟隨實際網站發布更新。只儲存原稿或到達預定時間，不代表已上線。既有發布流程完成建置與部署後，更新流程自動處理對應文章，不需要每篇手動建立索引。

初次正式啟用服務與預算後，後續合格發布在既有授權範圍內自動更新。若新版網站已上線而向量索引未就緒，先提供新版關鍵字搜尋；不使用舊內容補位。草稿、未到公開時間與私人內容不進入公開索引。

API 逾時、額度用完、版本不一致或模型不可用時，保留關鍵字結果。未設定預算時遠端模式維持停用。正式搜尋只讀取公開靜態資產，輸入不觸發模型；任何未來遠端啟用仍須另行確認處理方式與隱私，不能由本機預覽或本次部署推定授權。本站不將原始查詢與讀者歷史保存為分析紀錄。

## 後續改用 EmbeddingGemma

免費待遇及品質確認後，依版本切換流程重新計算整份 Google 向量索引，核對輸入格式、模型設定與 768 維輸出，再一起切換文章及查詢模型。不得混用兩個模型的向量，也不因查到價格就直接更換線上查詢模型。

## 只使用免費額度

本次授權的付費超額為零。文章初次建立向量、後續更新、讀者搜尋、測試與重試都計入用量；向量保留版本及支援服務也須符合免費條件。額度不足、用量不明或無法確認免費資格時，停止遠端處理，保留關鍵字搜尋，不自動升級或切換付費服務。

正式啟用前須確認供應商能強制阻止本次服務產生付費用量。若使用既有付費帳戶且其他程式也會耗用共用額度，單靠本功能的計數器不能保證零超額；無法確認有效的供應商限制時，語意服務維持停用。可以另評估隔離的免費環境，但本次不建立帳戶或變更方案。

確認免費條件後，才設定非零的免費使用量上限，並先保留至少兩成餘裕；金額上限仍是零。免費額度重設須依供應商時間及實際狀態確認，不因台灣跨日就自行歸零計數。告警只是提醒，不是阻止付費的機制。

## 驗收與目前狀態

目前保留三項能力、６６個 Given／When／Then 情境及２７項任務，２４項完成。沿用既有測試、完整本機驗證與實際瀏覽器驗證，沒有新增強制 CI。早期未完整保留逐情境先紅後綠證據的限制照實保留，後續已重現的紅綠結果不回填成早期都曾發生。

驗收涵蓋中文、技術詞、同義詞、分頁、鍵盤、手機與明暗主題，以及失敗、撤回、版本衝突、用量與逾時；內部篩選／排序契約保留，讀者介面已簡化。評測資料隨有來源的公開文章累積，不設題數、分類配額或百分比門檻；模型文件、模擬與本機比較不代表雲端真實品質通過。

靜態搜尋已由 main f488015 正式部署，部署與手機驗收紀錄見 [production-acceptance-20261021.md](production-acceptance-20261021.md)。本機 Ollama 比較與 BGE-M3 頁面實測已完成；雲端模型及向量服務仍未建立或啟用。AI 問答不在本次範圍。
