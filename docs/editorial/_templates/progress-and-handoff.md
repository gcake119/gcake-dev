# 連載進度與銜接紀錄｜通用模板

> 用途：各系列從第一篇開始使用，定稿後持續更新。複製到 `docs/editorial/<series-slug>/progress-and-handoff.md`；這是內部編輯記憶，不是對外文章、Series manifest 或發布狀態資料庫。

## 維護原則

- 每篇獨立對話；新對話先讀系列企劃、此文件、上一篇定稿及必要的少數前文。
- **文章定稿後**才將進度標記為定稿；討論中、初稿或 ready 不等於正式定稿。
- 已定稿正文是實際論述的權威；Series manifest 是公開章節、順序與進度的權威；本文件只保存跨對話需要的決策脈絡。
- 優先保存論點與證據、已談／未談界線、當時知道／後來理解／目前不知道，避免重複正文、完整對話、長篇 commit 流水帳。
- 區分「原始需求／當時決策／後來驗證／尚未證實」；Git commit、測試、本機演練、PR、正式部署與實際公開驗收各自標明。
- 有重大改動再更新系列企劃；對未公開篇目允許改題、合併、重排。已公開篇目保留實際發表位置。
- 每次修改可保留簡短更動摘要；不需為每篇複製一份整套交接文件。
