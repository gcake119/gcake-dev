# 系列寫作企劃｜通用模板

> 用途：新系列開始時，複製到 `docs/editorial/<series-slug>/series-plan.md`，由該系列獨立維護。
> 此檔是跨系列通用的**結構模板**，不放任何單一系列的正式篇目；每個系列的企劃及銜接紀錄各自演進。
> 正式正文、Series manifest、Git／OpenSpec／驗收紀錄各有權威來源，企劃不得取代它們。
