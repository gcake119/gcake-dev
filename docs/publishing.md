# Publishing

## New posts

```text
Markdown in gcake-dev
→ Git commit
→ GitHub Pages
→ canonical = gcake-dev Pages
→ Paragraph
→ Arweave permanent published snapshot
```

## 2026 iThome posts

```text
Markdown in ithome-2026
→ old GitHub Pages
→ canonical = old page
→ rendered by gcake-dev
→ optionally synchronized to Paragraph using original publication date
→ Arweave permanent published snapshot
```

Paragraph is never an editing source. Changes are made in the owning Git repository and then synchronized outward.
