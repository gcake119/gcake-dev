## Token 對照

### 色彩

所有正式色彩都集中在 `:root` 與 `:root[data-theme="dark"]`。元件應引用語意 token，不直接寫入新的 hex、rgb 或 oklch 值。

- `--paper`：頁面底色與目前項目表面。
- `--paper-deep`：引用、程式碼、展開區與 hover 次層表面。
- `--ink`：主要文字。
- `--ink-soft`：摘要與次要敘述。
- `--muted`：metadata、日期與輔助文字。
- `--rule`、`--rule-soft`：結構分隔與邊框。
- `--accent`：連結、焦點與主要操作。
- `--button-ink`：實心主要操作上的文字。

新增功能狀態色時，必須同時定義明亮與暗色 token，並提供非顏色線索；不能在單一元件內臨時加入一個只適用單一主題的值。

### 寬度與字體

- `--content: 62rem`：全站框架。
- `--reading: 44rem`：文章與簡單頁面。
- `--sans`：跨平台系統無襯線字體。
- 根排版：`17px / 1.8`；正文 `.prose`：`1rem / 1.9`。

公開站沿用既有值；後台字級、間距及圓角依文末已採納規範。重複用途以 CSS custom property 共用，不建立額外元件套件或新 CI。

## 元件重用規則

### 導覽與圖示

公開站由 `src/components/Icon.astro` 渲染圖示，Vue 後台以原生 SVG 渲染；共用路徑資料集中於 `src/components/icon-paths.ts`，不得將 Astro 元件直接匯入 Vue。線條均採 24×24 viewBox、currentColor、1.7 stroke、圓端點與圓接角。新增互動圖示時，由連結或按鈕提供可及名稱；不要讓圖示和父層重複朗讀。主要導覽必須保留 `aria-label`、`aria-current` 與鍵盤焦點。

### 操作層級

- 主要操作：`.primary-link`。
- 次要文字操作：`.text-link` 或一般語意連結。
- 只有圖示的正方形操作：沿用 `.theme-toggle` 或 `.social-link` 的 44px 目標模式。

不要新增沒有功能差異的按鈕變體。若操作只是導覽，優先使用 `<a>`；若會改變目前頁面狀態，才使用 `<button>`。

### 編輯式列表

系列、文章與主題列表以分隔線、留白和文字層級組成，不包成獨立浮動卡片。新列表應先沿用 `.reading-series`、`.post-row`、`.chapter-posts` 的形態，再決定是否真的需要新元件。

### 長文內容

所有 Markdown 正文放在 `.prose`。寬內容必須明確使用 `figure`、`.wide-content` 或 `.mermaid`；不能讓任意元素自行突破閱讀寬度。程式碼、表格與圖片的手機行為由全站樣式處理。

## 頁面組成

- 首頁：`home-intro` → 連載系列 → 最近文章 → 訂閱入口 → 其他系列 → 全部系列入口。
- 系列總覽：`index-header` → 依公開狀態分組的 `SeriesEntry`。
- 系列頁：`series-hero` → 章節與篇目 → 來源說明。
- 文章頁：breadcrumb → article header/meta → `SeriesNavigation` → 本篇目錄 → `.prose` → 精簡訂閱提示 → pagination。
- 搜尋頁：結果狀態與清單；搜尋輸入只存在全站導覽。

## 響應式與主題實作

- 公開站主要 breakpoint 是 `700px`；`400px` 與 `360px` 只處理窄導覽微調。
- 主題使用 `data-theme="light|dark"`，初次進站跟隨 `prefers-color-scheme`，手動選擇儲存在 `gcake-theme`。
- 主題初始化放在 `<head>` 的 inline script；不要移到延遲載入的客戶端元件，以免出現錯誤主題閃爍。
- 手機表格由 `BaseLayout.astro` 依真實 `<th>` 填入 `data-label`；修改表格呈現時必須保留欄位語意。

## 已知缺口

- 後台 danger／warning 已納入下方色票；成功沿用 accent 並搭配文字，不新增另一套成功色。
- 尚未有真實的獨立本地文章可做完整 rendered QA。
- 多系列與無系列狀態已有程式邏輯，但最近一輪未用正式內容 fixture 完整渲染。
- 既有公開站本機紀錄不是完整 WCAG 稽核，也不能替代正式部署或獨立人工驗收；後台正式部署證據見 [2026-10-19 部署紀錄](publishing-cms-deployment-20261019.md)。

## Publishing Admin 工作介面（2026-10-19）

本節只適用於後台。依使用者採納的介面審查報告與 Spectra change「simplify-admin-workflows」實作；已部署的 commit `1f3e8cf` 與正式四組驗收見 [部署紀錄](publishing-cms-deployment-20261019.md)，不宣稱獨立人工驗收。

- 文章、系列、發布管理使用獨立工作入口；文章為預設入口，發布摘要保留下一篇、預計時間與需處理數。
- 每個真實操作情境最多兩個按鈕，一主一次；「更多操作」若使用按鈕也計入。不能另排第二串按鈕規避上限。設定使用原生收合區，選項使用有標籤的選單，收合入口本身不執行資料變更。
- 文章主要操作僅保留「儲存文章」。正文工具使用兩個 SVG 圖示：單一檢視按鈕依原文、預覽、並排循環；圖片按鈕直接開啟媒體庫。圖示具白話輔助名稱與提示，檢視旁顯示目前模式，保留內容、游標及實際閱讀位置。媒體庫提示並支援貼上、拖入圖片。
- 介面使用「儲存系列」「網址代稱」「文章已儲存」「狀態待確認」等白話。內部儲存工具、檔案格式、版本參數與原始狀態碼不出現在日常操作文案；文章原文與外部平台名稱不任意改寫。
- 編輯正文優先。文章設定以「基本資料」「文章網址」分組，說明緊鄰欄位；暫存與刪除移至獨立「其他管理」。網站預覽及發布設定分開展開；固定操作列採不透明底色並保留焦點捲動空間。窄螢幕改為單欄。
- 未儲存內容離開前，以「繼續編輯」「捨棄修改並離開」確認；儲存衝突保留目前內容，不宣告成功。
- 已開始連載的系列呈現唯讀篇序與鎖定理由；不顯示可拖曳把手或停用的排序箭頭。
- 儲存、定稿、排程、網站更新、公開確認與外部通知分別呈現。未知結果先查證，不能為了簡化畫面新增無條件重複發布。
- 現有 QueueView 未回傳完整固定時間狀態；只有本次操作已確認固定的記錄提供恢復自動安排。重新查詢後無法確認時明示限制，不推測取消。補齊跨工作階段的固定時間資訊須另行擴充契約。

## 後台視覺基礎規範（2026-10-19 採納）

本節為使用者採納 design-conformance-report.html 後的正式後台規範。以目前 Spectra change `simplify-admin-workflows` 保留驗收及版本證據；公開站的排版與版寬不因本節而改動。

### 字級與閱讀

後台根字級維持 17px／1.8，系統無襯線字體；以下以相對根字級的 rem 表達，支援縮放。原文編輯器使用等寬字體。

| 用途 | 字級 | 字重 | 行高 |
| --- | --- | --- | --- |
| 頁面標題 | 26px；760px 以下 20px | 700 | 1.45 |
| 對話框、主要區塊標題 | 20px | 650–700 | 1.45 |
| 設定小節標題 | 16px | 650–700 | 1.5 |
| 正文、輸入內容、按鈕 | 17px | 400；按鈕 650 | 正文 1.8 |
| 欄位名稱、一般說明、狀態 | 14px | 400–500 | 1.7 |

重要錯誤及衝突說明使用正文尺寸，不能縮成 metadata。輸入內容不隨欄位標籤縮小。預覽正文行高 1.9，閱讀寬度上限 44rem；並排時隨欄寬縮小。介面說明盡量限制在 72ch，寬表格與原文編輯器例外。

### 間距、框架與控制

| 間距 | 用途 |
| --- | --- |
| 4px | 同一圖示工具群組內的緊密間隔 |
| 8px | 欄位名稱到輸入框、一般按鈕間距 |
| 12px | 欄位群組內的垂直間隔 |
| 16px | 次要區塊內距、手機小節間距 |
| 20px | 手機左右留白、中型區塊內距 |
| 24px | 設定小節上下內距、桌面左右留白 |
| 32px | 桌面設定說明與欄位的欄距 |
| 48px | 大型頁面區段間距 |

後台所有新增表單與設定群組的欄位垂直間距為 12px；一般按鈕（包含章節排序）相鄰間距為 8px，僅正文 SVG 工具群組使用 4px。欄位後的輔助說明保留 8px；欄位群組或其說明結束後，到執行操作列保留 16px。所有收合入口至少 44px 高，展開後入口到第一個內容區保留 12px；不可因巢狀預設 margin 重疊而失去間距。媒體卡片內的資訊、插入操作與管理區以 8px 分組，管理區展開後沿用 12px／16px 規則。錯誤、空白狀態與換行後的按鈕仍適用相同規則。瀏覽器原生確認框的排版由瀏覽器管理，專案只驗收取消不變更資料。

媒體庫按鈕列與下方貼上／拖入提示區之間，需保留 16px 垂直間距；同列按鈕之間為 8px。桌面、手機與明暗主題皆須量測實際邊界距離，不能只確認使用了間距變數。

後台框架上限 72rem、760px 以下改單欄；公開站保留 62rem／700px。後台 360px 以下仍保留 20px 左右留白，不另壓縮文字。互動按鈕、原生收合入口及輸入控制至少 44px 高；方形圖示按鈕 44×44px、圖形 22px、圓角 5px。排程輸入、媒體庫與編輯區使用相同尺寸角色。分隔線 1px；焦點外框與光學微調不強迫套入間距刻度。以分隔線與留白組織資訊，不增加裝飾陰影或浮動卡片。

### 色票及狀態

所有元件只引用語意色彩變數。下表數值皆為 OKLCH；原有 accent-soft、rule-soft 與品牌圖形色值繼續沿用公開站，不另改色。

| 角色 | 變數 | 明亮 | 暗色 |
| --- | --- | --- | --- |
| 底色 | --paper | 98% .007 250 | 22% .025 250 |
| 次層表面 | --paper-deep | 94% .023 250 | 28% .032 250 |
| 主要文字 | --ink | 25% .028 250 | 89% .014 250 |
| 次要文字 | --ink-soft | 43% .025 250 | 80% .02 250 |
| 輔助文字 | --muted | 48% .025 250 | 72% .025 250 |
| 分隔線 | --rule | 82% .025 250 | 38% .023 250 |
| 主要操作與焦點 | --accent | 47% .11 250 | 75% .085 250 |
| 實心按鈕文字 | --button-ink | 98% .007 250 | 22% .025 250 |
| 危險操作與錯誤 | --danger | 48% .16 28 | 76% .13 28 |
| 注意標記 | --warning | 57% .12 75 | 78% .1 75 |
| 對話框遮罩 | --overlay | 10% .02 250 / .72 | 10% .02 250 / .72 |

狀態必須搭配文字，不單靠色點辨識；警示色用於邊框或標記時，說明仍使用主要文字色。共用變數集中於根層及暗色主題，對話框不可直接寫色值。成功使用 accent 與白話文字，儲存不等於公開或通知完成。

### 驗收範圍

必須檢視桌面與 390px，兩種明暗主題，共四種組合。確認標題、欄位、輸入內容、間距、按鈕尺寸、媒體庫、焦點與長文；窄螢幕沒有頁面水平溢出，長標題不擠掉儲存按鈕，失敗及衝突提示可讀。重用既有本機測試與瀏覽器驗證，不新增強制 CI。本節是驗收規範，不是完整無障礙認證，也不能單獨作為部署或獨立人工接受證據；已完成的正式部署另見 [部署紀錄](publishing-cms-deployment-20261019.md)。

## 公開文章探索本機候選（２０２６－１０－２１）

遵循 `build-article-discovery-knowledge` 與使用者最新確認：搜尋結果保留４４rem閱讀寬度，正常畫面只有導覽列搜尋框、結果數量與緊湊文章列表；不顯示篩選／模式選單、清除篩選、建議用詞或處理說明。必要時保留重試及分頁，控制至少４４px。高亮引用雙主題語意 token，使用文字節點及 `mark`。正文之後依序為延伸閱讀、既有訂閱與系列導覽、相關文章、原生引用收合區；沒有內容的群組不顯示。沒有裝飾卡片、浮動側欄或無功能的問答輸入。

這是本機候選的實作對照；截圖、品質限制及正式啟用邊界見 [文章探索操作手冊](article-discovery-runbook.md)，不代表獨立人工作品驗收。
