# ADR-001：Cloudflare 免費語意搜尋

日期：２０２６－１０－２１。狀態：已採納；實際啟用結果另見操作與驗收證據。

## 背景與授權

文章搜尋的精簡畫面與本機 BGE-M3 已確認；PR ＃５０提供靜態搜尋，PR ＃５１整理正式驗收文件。使用者本次明確授權合併、部署、以 Computer Use 設定 Cloudflare，並確認「完成接線與驗證後啟用正式語意搜尋」及「Cloudflare 相關決策要放進專案」。

既有要求「只使用免費額度，付費超額上限為零」持續適用。使用者另確認：採免費方案硬上限，自動按 Cloudflare 每日重設時間給本站保守額度，不需每天人工重開。

## 採納的決策

１．只使用 Cloudflare 託管的 `@cf/baai/bge-m3`，開發者是 BAAI；這是使用者已授權的暫時例外。文章與問題都採 plain 格式、１０２４維、正規化及 cosine。EmbeddingGemma 的免費待遇與品質核實後，仍須整套相容索引切換；不得混用向量、自動換模型或加入重排／生成模型。

２．沿用目前帳戶 `979a3735f8dfa269e7474135f348cfdf` 的 Workers Free，不升級、不加購、不使用 AI Gateway 預付額度或付費替代。免費方案的供應商硬性上限才是零付費超額的依據；提醒通知或本站計數器不能取代它。帳戶改為允許超額付費、模型條款不適用或證據過期時，停用語意服務並重新確認。

３．目前官方 Workers AI 免費量是每日１００００ Neurons，UTC ００：００重設；本站使用至多８０００，含建索引、測試、未知結果與查詢。以 UTF-8 輸入位元組保守預留，不確定結果不退額度、不自動重試。這是應用層上限，並非供應商即時餘額。當期共享用量、來源與預留紀錄必須可追溯。

４．只在帶有明確 `verified-workers-free-utc` 決策且其餘啟用證據有效的設定中，以 Cloudflare 伺服器 UTC 日期建立當日額度。D1 以原子 `INSERT OR IGNORE` 建立一次，已消耗的當日額度不會因請求、部署或重試而補滿。其他未核實／允許付費的環境不能沿用這個例外。

５．以獨立搜尋 Worker、D1 額度資料庫與 Vectorize 索引隔離發文後台。正式名稱分別為 `gcake-public-search-production`、`gcake-search-admission-production`、`gcake-public-search-bge-m3`。搜尋服務不持有 Admin、GitHub 發文或 Substack 權限；不新增排程或通知流程。

６．Vectorize 的儲存與查詢維度各自扣抵免費額度，準備、保留與使用中版本一起計算。目前３３篇、２６３３段的單份 BGE 索引為２６９６１９２維；兩份完整副本會超過５００萬免費儲存維度，因此不得默默雙份保留。新版本準備超額時先維持當期關鍵字搜尋，不升級或恢復舊的已撤回內容。索引變動仍須核對當期帳戶用量及部署來源。

７．讀者仍只有一個搜尋框、結果數量與文章列表，必要時有分頁和失敗重試。送出查詢才呼叫模型，輸入時零模型請求。額度不足、逾時、服務故障或版本不合均保留／重新載入當期關鍵字結果，不產生回答。

８．公開文章段落與送出的查詢可由 Workers AI 處理；不保存原始查詢或原始 IP。只在額度資料庫保存短期、帶密鑰且逐分鐘變更的雜湊識別。關閉 Worker 的應用觀測記錄，不啟用 AI Gateway 記錄或快取。Cloudflare 的一般推論內容不訓練且不於處理後保留，但操作中繼資料、儲存服務與法令例外需分開說明；不宣稱平台完全零紀錄。讀者說明放在既有「關於」頁，搜尋畫面不增加說明段落。

９．只有實際 provider 輸出、公開來源與相容索引、完整本機 gate、main CI、正式資產讀回及 Computer Use 通過後，才啟用正式端點。回復方式是關閉語意開關，保留目前靜態內容；不重新部署會暴露已撤回文章的舊站。

## 持續更新索引的後續授權（歷史，已由雲端排程取代）

使用者另明確要求「持續更新雲端索引」。採本對話每小時一次的 Codex 持續任務，允許依既有流程更新已公開文章的搜尋索引及相容 corpus 提升；此為第５點「不新增排程」的限縮例外，僅限索引維護，不含發文或訂閱者通知。沒有新版本時只讀取與比對，不呼叫模型、不寫入索引。詳細流程見 [持續索引操作紀錄](../../openspec/changes/build-article-discovery-knowledge/continuous-index-maintenance-20261021.md)。

變更時仍須核實當期免費方案與所有版本的儲存量，先在既有共享 D1 額度中原子預留本輪最壞成本，保留未知結果的扣額，完成供應商讀回與公開版本重查後才提升。存取不足、缺少可安全執行的工具、另有未完成輪次或操作者已停用服務時，保留關鍵字搜尋並回報；不藉本任務更改開關、推送 Git、重新部署、換模型或升級付費。

每日額度自動重設與免費／隱私證據核實仍是兩件事。現有２０２６－１１－２０ UTC ００：００期限不因持續任務而延長；到期未核實即停止雲端處理。此任務依賴本機 Codex 可執行及既有帳戶權限，不宣稱為不依賴本機的 Cloudflare 常駐排程。

## 取捨與後續

免費方案用完即降級，接受部分讀者只得到關鍵字結果。模型品質依當期真實文章與已凍結的可用題目檢視，不設最低題數或固定品質百分比，不補造資料。網站發布不等於語意索引已就緒；未有相容版本時必須保持新版關鍵字搜尋。這份決策不宣稱所有歷史與雲端驗收已完成，實際狀態以驗收收據與操作手冊為準。


## 雲端自動同步決策（２０２６－１０－２１）

使用者明確要求將索引更新也部署到 Cloudflare、停用本機每小時任務，驗證後啟用。此決策取代前節的本機代管方案。沿用既有搜尋 Worker 的 Cron Trigger，每分鐘執行一個有進度紀錄的批次，每批最多１６段；沒有新公開版本就不呼叫模型、不更改向量或作用中版本。讀者與背景更新都不依賴本機開機。原 Codex 任務 automation-2 已暫停，不能與雲端排程並行寫入。

只讀取 GitHub Pages 真正公開、資產雜湊核對通過的文章；儲存草稿、Git 合併或排程時間到達都不代表可以建索引。沿用 BGE-M3 plain／１０２４維、相容內容快取與同一 D1 每日預留機制；免費上限、未知結果不退額度、供應商證據期限及操作者停用持續適用。不持有人員 OAuth、GitHub 或發文權限，不改文章排程與訂閱者通知。

D1 保存單一租約、進度、已核實向量清冊、待讀回向量及３０天操作收據。推論前預留，結果先保存再上傳；有保存結果的上傳可以安全重做，結果不明的推論停止並等待處理。所有目前段落完整讀回、修訂及數值核對通過且公開版本未變，才條件式提升作用中 corpus。只清理清冊可證明屬於本搜尋、已不在目前公開文章的舊向量；未知資料不刪除。每分鐘檢查不等於新文章一分鐘內就完成：更新會分批，供應商延遲或額度不足時保留新版關鍵字搜尋。

啟用順序是完整本機驗證、隔離雲端驗收、不含排程且背景停用的正式部署、正式搜尋核對，最後才開啟排程。只增加索引同步；搜尋介面、Pages 版本、模型及免費方案不變。正式版本與實際驗收見 [雲端同步紀錄](../../openspec/changes/build-article-discovery-knowledge/cloud-hosted-sync-20261021.md)。

## 公開來源下載修正（２０２６－１０－２２，本機候選）

使用者授權重新檢視逾時與資料讀取，選擇最簡單合理的方案。原始兩秒只針對小型版本清單，沒有實測或供應商硬限制依據；實作卻把約２．８ MB 的文章資料及再次完整下載也放在短期限內。這次保留直接讀取 GitHub Pages，不增加 D1 快照、遷移、資料副本或新服務。獨立 index／passages 並行下載並核對雜湊；回傳前只重新下載 manifest，比對 corpus 與兩份資產網址／雜湊，異動即拒絕舊結果。

本機候選採分開期限：讀者搜尋的小型 manifest 每次２秒、完整來源合計１５秒、語意請求整體２０秒、瀏覽器含最終版本核對２２秒。這些是可重新檢視的應用層等待預算，與免費額度或計費硬上限無關。１５秒依本機單次約９．８秒的完整並行下載留出餘裕，不宣稱 Cloudflare 一定能完成。小型 manifest 保留短時間快速降級；本機也觀察過一次２秒初始化逾時，暫時性網路失敗仍會降級，不宣稱已消除所有５０３。背景索引與前景準備既有３０秒來源預算保留。

關鍵字文章、結果數量與分頁先顯示，語意搜尋在同一頁補充；等待中仍能翻頁或改查詢，新查詢取消舊工作。失敗保留關鍵字與手動重試，不自動重試推論；初始來源失敗不扣模型成本，已預留但結果不明的推論仍不退額度。固定來源、大小上限、雜湊、撤回／版本核對、錯誤階段識別與隱私界線保留。未新增查詢、IP 或診斷持久紀錄。

此節取代前次診斷工作中「不延長來源／整體期限」的限制，保留當時證據。BGE-M3、免費方案及每日保守上限、證據到期、兩個正式開關與 cron 不變。本次未部署、未推送、未呼叫雲端模型或修改正式資料。瀏覽器等待期限屬於靜態 Pages 程式；未來如獲部署授權，須協調發布 Worker 與 Pages，單獨更新 Worker 仍會被舊瀏覽器程式的五秒期限中止。

完整修正、取捨與本機驗證見 [來源下載修正紀錄](../../openspec/changes/build-article-discovery-knowledge/source-download-repair-20261022.md)。

## 穩定內容身分與有界續作（２０２６－１０－２４，本機候選，尚未部署）

使用者授權實作 `fix-discovery-corpus-identity` 並完成本機驗證；不授權提交、推送、PR、正式模型／資料操作或部署。搜尋內容身分採有版本的確定性投影，包含公開資格判定後的文章集合、修訂、檢索中繼資料與連結、段落、詞彙、推薦及設定；還原時間、建置時間與Git版本另存追溯，不再單獨觸發重建索引。完整快照釘選驗證及manifest各資產digest仍保留；同身分也不能略過來源完整性檢查。

延續每分鐘cron及每批最多１６段，同輪最多完整讀回一批並準備下一批，新上傳等下輪讀回。保留４５秒步驟期限；讀回後已用１５秒即保存退出，留下既有３０秒操作預算。每輪基本控制／讀回預留４０個admission單位，準備階段另預留最多３２筆placeholder／payload寫入，讀回後續作則獨立預留７２個單位；向量讀取與推論／儲存各自先預留。這是保守應用層計數，不是供應商帳單。未知推論仍不重播、不退額，租約／policy條件仍限制進度及提升。

## 差異同步與持久續作（２０２６－１０－２６，本機架構候選）

使用者授權從第一性原理修補架構。公開集合版本不再兼任向量存放位置：物理 namespace 由已核准 modelConfig 的 SHA-256 決定，公開 corpus 仍是權威的資格／版本集合。D1 為已完整讀回的段落保存物理 namespace 與完整檢索 metadata 的 hash；文章、修訂、文字 hash、模型與 metadata 全相符的舊證據可跨公開版本重用。新版本只處理差異；真正修訂仍失效，撤回的 owned 向量確認不存在後才提升。現有 public/active 版本屏障保留，同步中提供當期關鍵字結果，不以混合索引或擴大 topK 掩蓋召回問題。

上傳後保存 provider mutationId，先確認供應商報告已處理該操作，再完整核對值／namespace／metadata。可讀仍不完整時持久保存下一次檢查時間，間隔由一分鐘倍增至最多三十分鐘；單輪不 sleep、不忙等。quota 不足只保存次日 UTC 的續作時間，既有 Cron 自行續作；舊日扣額、未知推論與證據期限維持，不能自動續期或退款。此變更不調高 requests500／vectorQueries500，也不把應用操作計數稱為官方查詢維度或帳單。

新增 0005_vector_proofs.sql 為 additive migration，舊 rows 與 receipts 保留。缺少新 proof 的舊向量必須一次完整轉換；舊 pending 不能直接換 namespace。activeVectorNamespace 只有完整同步 promotion 才設定，新讀者不接受只存在舊 activeCorpusId 的狀態。本機候選尚未部署；原 INDEX_SYNC=false／SEMANTIC=true 維持，正式 migration、對帳與恢復須另獲當次授權。回復須保持同步停用及當期關鍵字，不把舊 Worker 裝回已遷移的實體配置上。

詳見 [架構修補與正式遷移界線](../../openspec/changes/fix-discovery-corpus-identity/architecture-repair-20261026.md)。本節取代舊「每個公開版本搬移全部向量」的未來執行契約，保留所有歷史證據。既有４．２全量 provider audit／自然收據及４．３真人相關性驗收均不由本機 proof 重用代替。
