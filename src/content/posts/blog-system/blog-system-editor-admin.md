# 用 ChatGPT 寫文章，也想保留自己編輯的空間

目前我主要透過 ChatGPT 討論主題、整理大綱、修改文章，再請它更新檔案。從還沒整理好的想法開始，透過來回討論，慢慢收斂成一篇文章，這個方式很適合我。

不過，有些修改很小，例如換幾個字，或把圖片移到另一段後面。已經知道怎麼改時，自己直接操作比較方便，不必再描述位置、交代修改方式，然後確認結果。因此，我替部落格做了一個編輯後台，讓自己可以打開文章修改。

## 討論與編輯，各有方便的地方

文章要寫什麼、段落怎麼安排，我仍然會和 ChatGPT 一起討論。有時候只覺得某一段不太順，還說不出原因，就可以透過對話釐清，再決定要刪減、補充，或調整順序。

後台則提供直接修改文字、調整圖片位置的入口。之後加入可以點選、操作的互動內容時，我也希望能方便編排，確認整篇文章的閱讀效果。

## 做後台，也練習讓操作更順手

做後台時，我開始思考：打開畫面要先看到什麼？儲存按鈕放哪裡容易找到？不常用的設定能不能先收起來？

後台要處理的功能很多，包括編輯文章、管理圖片、調整系列與發布。每一項都有用途，但如果一次全部顯示在畫面上，就需要從很多選項裡找出當下要做的事。

因此，我需要取捨：哪些操作現在就要看見，哪些可以放到其他頁面，哪些設定等需要時再展開。判斷的起點，是我進入這個畫面要完成什麼工作。

例如編輯文章時，最需要的是看內容、修改與儲存，就讓這些操作留在容易找到的位置。系列管理與發布則安排在各自的入口，減少編輯時需要注意的事情。

這也是一次介面設計的練習：功能增加時，也要決定它適合在哪個步驟出現。

## 還需要實際使用，才能繼續調整

後台剛完成，目前還沒有大量使用，文章與檔案更新仍以 ChatGPT 為主。接下來碰到圖文編排與互動內容時，再確認哪些操作順手、哪些地方需要調整。
